# AI Gaming Club Management System

## 1. Project Description
AI Gaming Club Management System is a planned web application for PC and console bookings, station availability, and customer support through an AI assistant. The features described here are not implemented yet.

## 2. Problem Statement
Gaming clubs need an efficient way to manage reservations, prevent double bookings, and handle customer enquiries without relying entirely on staff.

## 3. Proposed Solution
A centralised platform where customers can book gaming stations, check availability, and interact with an AI assistant capable of performing real booking operations through secure backend services.

## 4. Project Objectives
- Automate gaming station reservations and customer support.
- Prevent overlapping bookings.
- Provide real-time station availability.
- Enable secure AI-powered booking operations.
- Provide administrators with tools to manage bookings.

## 5. Target Users
- **Customers:** Book gaming PCs and consoles, check prices, and manage reservations.
- **Administrators:** Monitor station availability, view and manage bookings when authorised, and view activity logs.

## 6. MVP Scope
- Gaming station management (30 PCs and 5 PS5 consoles).
- Booking creation, viewing, and cancellation.
- Availability checking and pricing.
- AI assistant with secure backend tool calling.
- Booking confirmation before changes.
- Basic customer interface and admin dashboard.

## 7. Out of Scope
- Online payments.
- Tournament management.
- SMS and email notifications.
- Voice AI assistant.
- Multi-club management.
